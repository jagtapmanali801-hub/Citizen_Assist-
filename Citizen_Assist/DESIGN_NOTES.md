# Citizen Assist — Pinterest V1 Design Build

This build follows the supplied Citizen Assist V1 board as the visual/UX reference while preserving the existing Citizen Assist content and functionality.

## Main journey
Home → Search → Services → Service Guide → Checklist/Progress → Official Portal → FAQ → About/Contact → Language & Accessibility → 404

## Included
- Citizen Assist logo and existing service data
- Blue/green civic visual system
- Search and service suggestions
- Service filters and detailed guides
- Interactive checklist/progress
- Official Maharashtra portal handoff
- FAQ, About, Contact and Privacy guidance
- English / Hindi / Marathi UI support
- Accessibility settings
- Local guidance chatbot
- Responsive mobile layout

## Important
Citizen Assist is an independent college project. It is not a government website and does not submit government applications. Actual applications happen on official government portals.
